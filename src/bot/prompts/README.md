# AI に渡すプロンプト

BOT が Gemini（と検閲なしモデル・画像モデル）に渡すプロンプトの文面です。コードは `src/bot/utils/prompts.js` の `render('chat/system', { … })` で読み、値を埋めて使います（`chat/system` はこのフォルダの `chat/system.md`）。

文面を変えるときはここの Markdown だけを直せば済みます。見出しや節の並びは、BOT が決まった見出しで探して入れ替えているところがあるので（下の「変えるときの注意」）、文言を直すだけにしてください。

## 書き方（Mustache）

| 書き方 | 意味 |
| --- | --- |
| `{{name}}` | 値に置き換わる（そのまま入る。HTML のエスケープはしない） |
| `{{#name}}…{{/name}}` | 値があるとき（空でない文字列・`true`）だけ入る |
| `{{^name}}…{{/name}}` | 値がないときだけ入る |
| `{{! メモ }}` | 編集する人向けのメモ。プロンプトには入らない（中に `}}` は書けない） |

- `{{#…}}`・`{{/…}}`・`{{! … }}` だけの行は、行ごと（改行も）消えます。
- ファイルが使う名前はコードがすべて渡します。渡されていない名前があると、その場でエラーになります（書き間違いですぐ気づけるように）。
- ファイルの最後の改行1つはプロンプトに入りません。
- 各ファイルの先頭のメモに、使える名前と何が入るかを書いています。

## ファイル

| ファイル | 使うところ |
| --- | --- |
| `chat/system.md` | メンションへの返事・イベント・フォーラム・チャンネルへの書き込みの下書きのシステム指示 |
| `chat/persona/*.md` | `/persona` の設定（依頼の「話し方」の欄） |
| `chat/reply-length/*.md` | `/replylength` の設定（依頼の「返事の長さ」の欄） |
| `chat/mature/open.md`、`chat/mature/filtered.md` | 下ネタ・大人向けの依頼の方針（依頼の「下ネタ・大人向けの依頼」の欄）。ふつうは `open`、セーフティフィルタが有効なサーバーでは `filtered` |
| `chat/last-step.md` | 調べる手順の上限に来たときの一言 |
| `chat/uncensored/*.md` | 検閲なしモデルへ引き継いだときの指示 |
| `polish/discord-note.md` | 返事の書き直し（replyPolish）に足す注意 |
| `video/*.md` | YouTube 動画の要約・長い動画の要約のまとめ |
| `lore/*.md` | サーバーの身内ネタ・ノリの取り出し（SERVER_LORE） |
| `wiki/extract.md` | wiki・X・Discord・Web のまとめからの知識の取り出し |
| `web/topic.md` | Web 検索で調べるテーマ |
| `stream/blurb.md` | 配信のイベント説明 |
| `emoji/describe.md` | サーバー絵文字の説明 |
| `image/cover.md`、`image/edit.md` | イベント・フォーラム投稿のカバー画像（英語） |
| `chat/pictures/*.md` | 依頼と一緒に見せる絵文字・添付画像の前置き |
| `chat/tool-compress.md` | 長いツール結果を、依頼に要る事実だけに縮める |

| `rules/pick-channels.md` | ルールが書かれていそうなチャンネル選び |

## 書くときの決まり

- **同じことを2か所に書かない。** 似た注意が2つあると、片方だけ直したときに食い違います。
- **前に書いたことを、あとで打ち消さない。** 「〜してよい。ただし〜のときは上を無視して〜」の形にせず、場合ごとにファイルを分けるか `{{#name}}` で入れ分けて、AI にはその場合の方針だけを渡します。
- **サーバーごとに変わることは `chat/system.md` に書かない。** 話し方・返事の長さ・下ネタと大人向けの方針は依頼の側に入れます（`chat/persona`、`chat/reply-length`、`chat/mature`）。システム指示はどのサーバーでも同じなので、Gemini のプロンプトキャッシュを1つで済ませられます。
- 検閲なしモデルには、下ネタ・大人向けの方針を `chat/uncensored/rules.md` だけで渡します（依頼の「下ネタ・大人向けの依頼」の欄は渡しません）。

## 変えるときの注意

- `chat/persona/*.md`・`chat/reply-length/*.md`・`chat/mature/*.md` は箇条書き（`- ` で始まる行。字下げした行も可）だけにしてください。BOT が欄ごと取り除くとき（検閲なしモデルに渡すとき）、箇条書きの終わりを欄の終わりとして見ています。
- `chat/system.md` を変えると Gemini のプロンプトキャッシュが作り直されます（次の返事で一度だけ）。
- `tools/*.md` の `## 引数名` はコードの引数名と同じにしてください。コードにない引数の節があるとエラーになります（書き間違いや消し忘れにすぐ気づけるように）。ツールの名前・引数の型・必須かどうかはコードが決めます。
- `sokudan/*.md` の選択肢の並びと段階の数はコードと合わせてください（違うとエラーになります）。並びを変えると判定の精度が変わることがあるので、ファイル先頭のメモを読んでから直してください。
