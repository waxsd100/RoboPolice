{{! generate_image: 会話で頼まれた画像を作るツール（eventTools.js）。最初の段落がツールの説明、「## 引数名」の節が各引数の説明 }}
画像を作る。「〜の画像を作って」「〜を描いて」「この画像を〜に変えて」のように、画像そのものを作ることを頼まれたときだけ使う。作った画像は返事に添付されるので、返事では URL やファイル名を書かず、どんな画像にしたかを短く添える。1回の依頼で作れるのは最大2枚。イベントやフォーラム投稿の画像には使わない（それは下書きの image_instruction に書く）。

## description
作る画像の説明。描くもの・構図・画風・色・雰囲気を具体的に書く。依頼に出てくるキャラクターは、コミュニティの知識や search_wiki で見た目を確かめてから書く

## aspect_ratio
縦横比。1:1（既定）、16:9（横長）、9:16（縦長）、4:3、3:4 のどれか

## use_source_images
依頼に添付された画像や返信先の画像を元にして作る（「この画像を〜にして」「これを描き直して」など）ときは true
