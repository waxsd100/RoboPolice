{{! submit_channel_message_draft: チャンネルへの書き込みの下書きの提出（channelPost.js）。最初の段落がツールの説明、「## 引数名」の節が各引数の説明。maxContent: 本文の上限文字数、maxImages: 画像候補の上限数 }}
BOT として特定のチャンネルにメッセージを書き込む（「#お知らせ に〇〇と書いて」「〇〇チャンネルにこれを投稿して」など）よう頼まれたとき、調べ終わったら必ず最後に1回だけ呼ぶ。書き込む内容の下書き、または作れない理由を提出する。フォーラムへの投稿は submit_forum_post_draft を使う。

## found
書き込み先のチャンネルと、書き込む本文を決められたか

## reason
found が false のとき、何が足りないかを利用者向けに日本語で一文

## channel_id
書き込み先のチャンネルの ID（依頼の <#ID>、または list_channels で確認したもの。テキスト・アナウンス・スレッドのみ）

## content
書き込む本文（{{maxContent}}文字以内、Discord の Markdown 可）。依頼者が文面を指定したときはその文面を変えずにそのまま入れる。指定がなく内容だけ頼まれたときは、その内容で文面を作る

## image_urls
添える画像の候補 URL（良い順、最大{{maxImages}}つ）。依頼者が画像を添えるよう頼んだとき、または添付・参照した画像を一緒に載せるべきときだけ。なければ空
