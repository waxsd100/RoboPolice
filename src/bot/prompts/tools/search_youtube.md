このサーバーに設定された YouTube チャンネルについて保存している情報（チャンネル登録者数・概要、動画の題名・公開日・配信日時・長さ・再生数・高評価数・コメント数・保存済みの要約、配信予定・配信中）や、指定された YouTube 動画 URL の正確な情報を探す。動画の再生数や投稿日・配信日、一番再生されている動画・一番古い動画・最新の動画、おすすめの動画・名作・神回などを聞かれたときに必ず使う。

## query
探したい動画の題名・説明・要約・内容を表す語、または YouTube 動画の URL（空白区切り。意味が近い動画も探す。全動画から再生数順・新しい順・古い順で見たいときは省略可）

## sort
並び順。再生数が多い順・人気順は views、古い順・最初の動画は oldest、新しい順・最新の動画は newest、関連度順は relevance（省略時は自動判定）
